GOLDEN GAMING DEAL — ONE-PAGE WEBSITE

Preview: Open index.html in a web browser.

Publish using GitHub Pages:
1. Create a NEW GitHub repository (for example golden-gaming-deal-website).
2. Upload index.html and the assets folder (including all four .webp files) to the repository root.
3. Open Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
4. Wait for the Pages website link to appear. Test on your phone.
5. To use a custom domain, buy/own the domain and configure its DNS and GitHub Pages custom domain setting.
